# Accessibility (A11Y)

* **Contrast Ratio:** Ensure text meets WCAG 2.1 contrast guidelines (at least 4.5:1 for normal text, 3:1 for large text).
* **Dynamic Text:** Ensure UIs scale gracefully with system font adjustments.
* **Semantics:** Wrap key components with `Semantics` widgets to provide clear descriptions for screen readers (TalkBack / VoiceOver).
